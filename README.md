# redfrogblack-pages

Static copy of the redfrogblack website for GitHub Pages (migrated from Vercel, 31 Oct 2026).
Built for the domain ROOT (absolute paths like /assets/...), so it renders fully only on the custom domain.
The site files are stored as one base64-packed tarball in blobs/ (unpacked by the workflow; file list in manifest.txt).
Custom domain NOT set yet. Stage 2: add site/CNAME and set the domain in Settings > Pages.
